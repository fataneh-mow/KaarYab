# KaarYab Afghanistan 🚀

## Project Name

**KaarYab Afghanistan - Opportunity Finder Platform**

---

## Project Description

KaarYab Afghanistan is a modern opportunity finder platform designed to help Afghan youth discover jobs, internships, scholarships, online courses, remote work, training programs, and skill-building opportunities in one place.

The platform provides a simple and organized way for students, fresh graduates, job seekers, and organizations to discover and share opportunities. Instead of searching through different websites, social media pages, and online groups, users can access useful opportunities from a single platform.

This project was developed as a final capstone project using modern web technologies including Next.js, React, Tailwind CSS, state management, API routes, and reusable component architecture.

---

# Problem It Solves

Many young people in Afghanistan face difficulties finding useful career and educational opportunities because information is spread across many different platforms.

KaarYab Afghanistan solves this problem by creating a centralized platform where users can easily:

- Discover jobs and internships
- Find scholarships and learning opportunities
- Search and filter opportunities based on their needs
- Save opportunities for later
- Share new opportunities with other users

The platform helps make opportunity discovery easier, faster, and more accessible.

# Features ✨

## Opportunity Listing

- Browse available opportunities
- View opportunities in card and list formats
- View detailed information about opportunities
- Search opportunities by title
- Filter opportunities by:
  - Category
  - Location
  - Opportunity type
  - Remote/on-site type
  - Deadline


## Opportunity Details

Each opportunity includes:

- Title
- Organization name
- Category
- Location
- Type
- Deadline
- Description
- Requirements
- Application link
- Tags


## Save Opportunity Feature

Users can:

- Save interesting opportunities
- View saved opportunities later

Saved opportunities are stored using LocalStorage.


## Opportunity Management (CRUD)

Users can:

- Create opportunities

- Delete opportunities

# How to Run Locally 💻

## Requirements

Make sure you have:

- Node.js installed
- npm installed


## Installation

Clone the repository:
```git clone YOUR_GITHUB_LINK```

Navigate into the project: 
```bash cd kaaryab-afghanistan``

Install dependencies:
```npm install```

Run the development server:
```npm run dev```

Open the application:
```http://localhost:3000```
